# Java Assignment

This repository contains **Java programs** developed as part of an academic assignment. It covers **core Java concepts**, including object-oriented programming, inheritance, polymorphism, arrays, loops, and conditional statements.

---

## 📂 Folder Structure

1. **Exercise 1 – Basic Programs**  
   - Demonstrates fundamental Java concepts such as:  
     - Input and output operations  
     - Loops (`for`, `while`, `do-while`)  
     - Conditional statements (`if-else`, `switch`)  
     - Arrays and array operations  
     - Functions/methods  

2. **Exercise 2 – Polymorphism**  
   - Covers **runtime polymorphism** (method overriding) and **compile-time polymorphism** (method overloading).  
   - Includes examples of dynamic method dispatch using multiple classes.

3. **Exercise 3 – Inheritance**  
   - Illustrates **single-level** and **hierarchical inheritance**.  
   - Shows how child classes extend parent classes and reuse properties/methods.

---

## ✨ Key Features
- Clear separation of exercises for easy understanding and execution.  
- Emphasis on **object-oriented programming principles**.  
- Each program is self-contained and can be executed independently.
